# 🍽️ ALPHA Restaurant

A responsive restaurant website developed using HTML, CSS, JavaScript, and Bootstrap. The project provides an engaging user experience with a modern design, interactive navigation, menu showcase, and contact section.

## Features

- Responsive Design
- Interactive Navigation
- Food Menu Display
- Contact Section
- Smooth Scrolling
- Modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
